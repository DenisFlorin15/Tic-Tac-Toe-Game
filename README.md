# Tic-Tac-Toe Text-Based Game

A classic, interactive Tic-Tac-Toe game built with Python. This project focuses on implementing game logic, handling user input, and managing a 2D board structure within a command-line environment.

## ✨ Features
- **Two-Player Mode:** Play locally with a friend (Player X and Player O).
- **Win Detection:** Automatically identifies winners across rows, columns, and diagonals.
- **Draw Detection:** Recognizes when the board is full and no player has won.
- **Input Validation:** Prevents players from choosing an already occupied square or entering invalid coordinates.
- **Dynamic Board Display:** The board updates and re-renders in the console after every move.

## 🛠️ Tech Stack

- **IDE:** PyCharm
